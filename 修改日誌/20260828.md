# 2026-08-28 修改日誌

## EndCap 組合體 3D 實體板成型
- 使用者指出標準金庫型封頭／封尾看起來不是「少折」，而是成型外側板面沒有出來，折邊像由箱內往外插。
- 根因：EndCap assembly 只使用 `folded_mesh_from_polygon()` 的零厚度 mid-surface，`T` 未進入 3D 成型；舊 placement 直接把 z=0 中心面當 mating face。
- 新增 `ae_engine.assembly_geometry.thicken_triangle_surface()`：由折後 mid-surface 建立 ±T/2 內外 skin、材料外周側壁與非共面 fold-edge bridge。
- `place_endcap_against_box_body()` 新增 `sheet_thickness`：Head 中心面向上外移 T/2、Tail 向下外移 T/2，使內側 skin 貼箱身、外側成型面位於箱外，折邊仍朝箱內。
- `phase6_final_scene_view.py` 組合體 Head/Tail 改渲染 physical sheet solid。
- `ae_engine/assembly_collision.py` shared world mesh API 同步支援 physical EndCap sheet，避免 viewer/collision 分叉。
- 標準金庫型 Fold Profile、5 道 BEND、2D、DXF 均不改。
- AI 庫與 Superpowers verification 同步更新。

- `phase6_final_scene_view.py` 新增 folded mid-surface edge extraction：保留外輪廓／through-hole 邊界，並以相鄰面法向判斷非共面 formed crease；排除共面 triangulation diagonal。
- Assembly Head/Tail 維持 physical solid 主面，額外疊加 folded mid-surface 的真實特徵線；不改 Fold Profile、CUTTING、CornerType、2D、DXF 或 assembly placement。
- 新增永久回歸：physical EndCap 加厚後孔輪廓仍可見；第一折必須有跨板面的真實 crease，不得只剩板厚側邊。

## 08:00 固定截角干涉診斷收斂為 relief-delta 局部碰撞區
- AI 自行檢查 07:10 版實際組合體畫面後，判定「947 段干涉交線」不合格：紅線沿正常長接縫與插入位置擴散，不是真正局部截角碰撞。
- 根因不是 renderer 顏色，而是碰撞 probe 錯把整片補回後 EndCap 拿去與 BoxBody 做 surface crossing，正常 mating seam 也會被計為相交。
- 新增 `restored_endcap_relief_delta()`：固定截角診斷只取 `restored material - production material`，只折起／加厚這一小塊補回材料後與 BoxBody 求 world-space 穿越。

- 視覺改為「命中的 relief-delta triangle 半透明紅面 + intersection segment 紅色粗實線」，因 target 已局部化，不會再把整片 EndCap 染紅。
- 關閉 `診斷時忽略固定截角` 時不再退回整片 production EndCap 做碰撞，右側提示先啟用固定截角診斷。
