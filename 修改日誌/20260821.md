# 2026-08-21 修改日誌

## 截角類型／裝配語意整合

本次不是單純改 GUI 名稱，而是把截角類型提升成製造與裝配尺寸鏈的唯一來源。

### 幾何引擎

- 新增正式截角類型：十字截角、貼外型、嵌入型、嵌入貼外型。
- 十字截角支援標準／單邊留肉／多切與方向、`xT` 參數。
- 貼外型固定高方向留肉。
- 嵌入型固定高方向多切，預設 `1T`。
- 嵌入貼外固定二級截角：貼外留肉＋嵌入留肉＋深度。
- **修正先前誤判：** `C04`／嵌入貼外的實際二級 CUTTING 必須維持 `側折 + 0.5T`；先前把二級位置誤算成 `39mm` 的版本已撤銷。UI 仍顯示「嵌入留肉 0.5T」，兩級之間剩餘材料由程式推導。
- `C01~C04` 僅保留相容讀取，進入引擎後轉換成新的製造語意。

### 箱身裝配尺寸鏈

- 箱身高度不再永久寫死 `H-2T`。
- 封頭／封尾有貼外關係時各佔 `1T`；純嵌入佔 `0T`。
- 因此支援 `H-2T / H-T / H`。
- 箱身孔位、固定特徵與面特徵的 Y 基準同步使用相同封頭／封尾偏移。

### 資料契約與製造 API

- `BoxBodyPartSpec` 新增內部欄位 `head_corner_policy` / `tail_corner_policy`。
- 製造 API 與 AE exporter／場景建立器全程傳遞同一份 policy，不另外重算裝配狀態。

### GUI／3D 折彎設計器

- 新操作流程移除 `C01~C05` 與 `0°/90°` 截角 UI。
- 使用者畫面改用繁體中文製造語意名稱與參數欄位。
- 修正十字截角切到「多切」時沿用舊方向的問題：預設回到「寬＋高、0.5T」。
- 截角快照、Bridge 原始狀態、`config.ini` 來回保存全部保留參數。
- 已知固定板件以繁體中文顯示截角摘要但不可修改。
- 指示燈盒／指示燈小門維持共享固定板件，即使切到「自訂」也不可修改截角類型。
- `fold_designer_original.py` 的製造幾何／操作模型維持原版；因新增全域字級，僅加入文字倍率。

### 繁體中文規則

- 使用者可見介面一律使用繁體中文。
- Superpowers 規格、實作計畫、驗證紀錄、交付說明與修改日誌使用繁體中文。
- Python 類別、函式、enum、欄位名稱與舊相容代碼屬程式內部識別字，為避免破壞 API 保留英文；文件會附上繁體中文製造意義。

### 封頭尾截角修正

- `FW=25、T=2、側折=15、嵌入留肉=0.5T` 時，正確二級 CUTTING 為 `16mm`，深度 `4mm`。
- 新增回歸測試，禁止文件與測試重新把 `39mm` 當正確答案。

### 全域文字大小

- 新增 **文字大小：小 / 中 / 大**。
- 小為現有字級 `1.0×`，中 `1.2×`，大 `1.4×`。
- 主 GUI 與 3D 折彎設計器皆可選擇，切換後即時套用。
- Tk/ttk/Canvas/Matplotlib 文字共用同一倍率；CAD/DXF 幾何不縮放。
- 選擇保存於 `config.ini` 的 `[UI] text_size`，下次啟動沿用。
- 新增 `ui_text_scale.py` 作為 GUI 文字縮放單一責任模組。


### 自訂模式（原未知類型）

- 使用者可見名稱由「未知類型」改為 **「自訂」**。
- 舊資料／舊字串 `未知類型` 保留相容讀取，自動視為「自訂」。
- 修正原本切入手動模式會使用另一份預設截角狀態的問題。
- 現在從已知型號切到「自訂」時，尺寸、折彎、使用者孔位資料保持原狀，只把目前固定截角規則複製成可編輯狀態。
- 金庫型封頭／封尾複製後：上方嵌入貼外、下方十字多切 `0.5T`，因此箱身高度鏈不再因上方十字預設而拋出 GeometryError。
- 3D 折彎設計器使用相同繼承規則，不再恢復舊自訂截角草稿。

## 三維真實開孔截角與視野填滿

- 三維預覽改用正式 `DrawingScene.CUTTING` 建立 material polygon，不再以完整矩形板面冒充製造輪廓。
- 圓孔、封閉 Profile 孔、指示燈孔、指示燈盒開口、盒體固定孔與小門視窗會在三維 mesh 中真正挖空。
- CornerType 截角直接使用現有製造引擎結果；三維層不另建截角公式。
- FoldChain 將同一份展開 CUTTING 分區後映射到折彎三維位置，保留實際缺料／孔洞。
- 視野由 mesh 實際 X/Y/Z bbox 各自 fit，移除舊 `max_b` 立方體限制。
- 只在 Phase6 bridge 的三維 axes 實例解除 Matplotlib `apply_aspect()` 強制正方形 viewport，避免左右大面積留白；不修改 Matplotlib 全域行為。
- 直接指示燈與指示燈盒模式所產生的 Door CUTTING 也帶入三維預覽。
- 新增 `tests/test_phase6_3d_cutting_mesh.py` 防止真洞、截角、折彎映射、非 cube fit 與寬 viewport 回歸。

## 三維留肉與基準檔孔修正

- 修正 `CROSS / 留肉` 小段材料在三維被 X/Y 兩個折彎同時帶走的錯誤。
- 留肉方向「寬」只跟上／下板面；留肉方向「高」只跟左／右板面，三維 mesh 以 fold-exemption region 決定折面歸屬。
- 三維 material 新增目前選定型號基準檔 secondary `CUTTING` 孔，基準孔不再只出現在二維預覽。
- 基準 `CIRCLE`、封閉輪廓與炸開 LINE 迴路都可成為三維真洞。
- 排除 stretched baseline scene 中重複的結構外框，避免誤判成超大孔。
- 新增 `tests/test_phase6_3d_retain_and_baseline.py`。
