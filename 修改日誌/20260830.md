# 2026-08-30 修改日誌

## 受電箱封頭／封尾下方外側包覆（WRAP）

- `WRAP` 不再視為箱身／封頭尾的第四種高階組合方式；它是**受電箱封頭／封尾下方專屬接合條件**。
- 箱身仍固定使用側背分離結構；封頭／封尾本身仍可各自使用 `INSERT / OVERLAY / INSERT_OVERLAY`，下方 WRAP 與這三種高階組合方式正交。
- WRAP 開啟時，下方截角使用 WRAP 專屬 Registry 規則，不直接沿用 INSERT、OVERLAY 或 INSERT_OVERLAY 的截角／展開結果。
- Head/Tail 的 WRAP 設定加入既有「先連動、再可分離」語意：通常上下相同；設定連動不代表直接複製另一端 Polygon/Blank。

### 可調預留

受電箱下方 WRAP 的兩個預留量改成獨立 mm 參數，放在「參數鎖定」解鎖區：

- `reserve_u`：X 預留，預設 2 mm。
- `reserve_v`：Y 預留，預設 1 mm。

正式幾何式：

- 第一級 X = 封頭／尾該側折 + 側板後折 - `reserve_u`
- 第一級 Y = `ybottom1` - `reserve_v`
- 第二級 X = 封頭／尾該側折
- 第二級深度 = `reserve_v`

預設 `側折=15、側板後折=15、ybottom1=15、reserve_u=2、reserve_v=1` 時為 `28×14 + 15×1`。

## 3D placement / piece-level solver

- 受電箱側背分離後面板改為獨立 piece-level 3D 幾何，Joint solver 可解析 `box_body:left_side / box_body:back / box_body:right_side`。
- 受電箱 EndCap 使用 Fold Profile core datum 進行 assembly-depth placement；此 core-origin 行為**只限受電箱**，金庫型／自訂既有 placement 契約維持不變，避免既有 INSERT/OVERLAY/INSERT_OVERLAY 回歸。
- Viewer 與 Collision Solver 現在由同一個 Family scope 決定是否使用 core-origin，避免畫面與求解位置分歧。

## 展開料（Blank）

- 每片板金的展開料資訊由 canonical final material 直接量測，不另建第二套 Fold 長度公式。

- Head/Tail 即使 WRAP 設定通常連動，也各自以自己的 final material 算展開料；兩者相同只能是幾何結果相同，不是互抄。
