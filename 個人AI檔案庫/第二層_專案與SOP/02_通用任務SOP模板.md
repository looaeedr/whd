# 📋 02. 通用任務 SOP 模板 (Task SOP Template)

> 當需要為特定工作（如：數據分析、爬蟲開發、報告生成）建立標準作業程序時，可複製此模板。

---

## 🎯 任務名稱：[請填寫任務名稱]

### 1. 任務目標 (Objective)
- 明確描述本任務要達成的具體成果與產出物。

### 2. 輸入與前置條件 (Inputs & Prerequisites)
- 需要哪些輸入檔案或資料？
- 需要依賴哪些環境、套件或權限？

### 3. 執行步驟 (Step-by-Step Procedure)
1. **第一步：資料準備與備份**
2. **第二步：核心處理與轉換**
3. **第三步：輸出與結果驗證**
4. **第四步：規格與經驗同步**
   - 若本次新增/修改程式行為、幾何規則、資料契約、UI 流程或修復 Bug，直接更新對應 SOP。
   - 若本次發現可重現錯誤模式或反面教材，同步追加至 `06_踩坑記錄與防錯經驗庫.md`。
   - 文件同步屬於任務完成條件，**不得等待使用者再次提醒**。

### 4. 品質檢查清單 (Quality Checklist)
- [ ] 產出物是否完整且格式正確？
- [ ] 是否有異常報錯或遺漏？
- [ ] 是否已記錄執行日誌？
- [ ] 若程式行為有新增/修改，對應 SOP 是否已在同一輪更新？
- [ ] 若有踩坑/根因/防錯規則，`06_踩坑記錄與防錯經驗庫.md` 是否已同步追加？
- [ ] 程式、測試、README/SOP 是否描述同一版本的真實行為，沒有舊規則殘留？

### 6. 檔案保真檢查（適用於更新既有檔案庫／規格包）
- [ ] 原始檔名／目錄是否保持，未自行改成英文或 ASCII 替名？
- [ ] 壓縮檔是否以 UTF-8 正確保存中文 entry 名稱，且已實際解壓驗證？
