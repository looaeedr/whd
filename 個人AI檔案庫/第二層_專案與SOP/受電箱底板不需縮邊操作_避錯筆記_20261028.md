# 受電箱底板不需縮邊操作 — 避錯

- 使用者要求取消「縮」是取消操作，不是使所有實體板件 shrink=0。
- 原始板件的左右縮量等內部參數仍是底板來源幾何的一部分，
  影響焊接固定孔和定位。保留已認證來源公式。
- 只移除受電箱 3D 設定中心的手動縮邊控制，不破壞其他箱型。
- 資料 schema 和既有提交 API 含完整來源幾何，仍需保留供讀舊檔與 MFG 比對。
- 新程式必須用 Tk widget 實測「縮邊」輸入消失，不能僅用字串測試冒充畫面證據。
