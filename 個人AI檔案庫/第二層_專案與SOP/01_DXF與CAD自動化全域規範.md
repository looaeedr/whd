# 📐 01. DXF 與 CAD 自動化全域規範 (CAD Global SOP)

## 🎯 應用場景
適用於雷射切割（CypCut、Trumpf、Bysoft 等 CAM 軟體）、折彎加工相關的 DXF 圖檔自動化處理與驗證。

---

## 🏷️ 圖層標準 (Layer Standards)
- `CUTTING`：外形切割線、內部切口與孔洞（**必須為 100% 完全封閉迴路**）。
- `BEND`：折彎線（標註折彎位置與方向，需為乾淨直線）。**每一條 BEND 必須對應一個實際 Fold Chain 折彎角度；沒有 `angle` 的 segment boundary 不得憑邊界位置產生 BEND。**
- `MARKING`：打標/刻字/定位記號（中心點或標記圈）。
- `CHECK`：驗證/輔助線層（僅供檢查，不進入加工切削）。
- **圖層保護原則**：嚴格保護原始圖層名稱與圖元屬性，未經確認不任意更動圖層與顏色。

---

## ⚙️ 幾何處理標準流程
1. **幾何檢查**：
   - 檢查端點是否重合（容差 <= 0.001 mm）。
   - 檢查是否存在未閉合的微連接（Micro-joints / Tabs / 斷點）。
2. **閉合修復 (Closing Geometry)**：
   - 將斷開的直線/圓弧依序連線或合併為連續單元，確保 100% 封閉。
3. **安全保存**：
   - 操作前備份至 `BACKUP/`。
   - 儲存時確保 DXF 版本相容性（預設使用 AC1032 / AutoCAD 2018 標準）。

---

## 📏 成品尺寸與 3D 標註標準（2026-08-22 更新）
- **3D 尺寸一律標註折彎完成後的包外尺寸（Finished Outside Envelope）**，不得直接拿 2D 展開板 `bbox/material.bounds`、折彎前 blank 尺寸、core 長度或 segment 累加長度當成 3D 成品尺寸。
- **單件 3D 與整箱 3D 必須分開定義尺寸語意**：
  - 單件板件視圖：標註該板件「折好後本身」的實際包外尺寸。
  - 整箱組裝視圖：標註完整箱體組裝後的目標包外 `W / H / D`。
- 3D 包外尺寸應由**折後實際外表面幾何 envelope**計算，並正確包含板厚 `T`；不得以折線中心、2D 外框或展開尺寸代替。
- 箱體輸入的 `W / H / D` 為**整箱成品包外目標尺寸**。因封頭／封尾的組合方式不同，箱身單件折好後的高度可能為 `H`、`H-T` 或 `H-2T`，但完整組裝後仍應回到目標 `H`。
- 尺寸驗證時必須同時檢查「單件折後包外」與「整箱組裝包外」，不得把兩者混為同一尺寸。

---

## 🔗 Final 2D 與 3D 折彎一致性（2026-08-23 更新）
- **Final 2D 是唯一製造幾何來源**：`CUTTING / BEND / MARKING / CornerType / Finished Boundary` 先在同一份 FinalScene 完成；3D 只把這一份 FinalScene 沿 BEND 折起來，不得另算第二套折法。
- **BEND 與折彎角度必須 1:1**：2D 有 BEND，3D 就必須有對應 angle；沒有 angle 就不得在 2D 產生假 BEND。
- **角度驗證與尺寸驗證分開**：例如設定 90° 折彎，需直接驗證相鄰折後面的夾角為 90°；不得用包外尺寸「看起來合理」代替角度驗證。
- 若 Fold Chain 的可選折段被刪除，對應 2D BEND、blank/material 外框與 3D 折面必須**一起消失**；禁止只刪折線卻保留舊板件尺寸。
- 任何 reader / adapter 遇到合法缺少的可選折段時，應視為「該折段不存在」，不得以「資料不完整」為由退回舊固定拓撲。

## 🎚️ Fold Chain 角度輸入與 2D/3D 同步（2026-08-23 更新）
- **操作員輸入角度就是折彎命令**：輸入 90° 就必須形成 90° 折彎；輸入 45°、60° 或其他角度亦同。不得把封頭／封尾角度硬寫成固定 90°，也不得因板件類型另套一組角度公式。
- UI 與 engine 若存在內部正負號座標慣例，該轉換只能是**透明表示層**；`UI → engine → UI` 必須無損回到原輸入值。derived profile 與 3D 必須使用同一筆 engine angle，禁止再二次換算。
- 封頭／封尾由箱身 Fold Chain 推導時，對應 BEND 的 angle 必須跟著來源 boundary 一起搬移；native reverse 只能改變順序／angle ownership，不能把 45°、60° 等輸入值重設成 ±90°。
- **視角不參與幾何角度**：相機 perspective / orthographic 僅是顯示設定，不得用來補償或掩蓋折彎角度錯誤。
- Phase6 按「確定」後，主 GUI 2D 結果必須重新使用 committed FinalScene；不得因分支變數、legacy 尺寸公式或 silent exception 把結果留在舊值或顯示 `-`。
