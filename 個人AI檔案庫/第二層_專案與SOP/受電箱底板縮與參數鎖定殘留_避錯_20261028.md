# 受電箱底板縮、參數鎖定關不掉：避錯

- **真正根因**：設定頁欄位移除了，但 `fold_designer_composition_registry_edges.py` 的 3D 四邊獨立輸入仍然存在；測試只看 SettingsPanel 元件樹會誤判修好。
- 不刪除物理縮量 `shrink_top/bottom/left/right`，只禁止受電箱操作員輸入；否則影響真實成型尺寸與固定孔。
- 原 3D Canvas 的 `parameter_lock_button.invoke()` 兩次通過，不等於使用者能用滑鼠按兩次；展開面板可能把 Canvas 擠出畫面。須在目前可見的設定與組合體診斷面板內提供同一狀態的「收合參數」。
- 兩種狀態的真實 GUI 測試要用 `winfo_ismapped()`、`.invoke()` 並確認關閉後 `winfo_manager()==""`；要測再開、再關。
- GitHub 合併不會讓已啟動的 Windows `python gui.py` 自動熱載入；必要時先保存使用者工作再關閉重開，不可未保存就強制結束。
