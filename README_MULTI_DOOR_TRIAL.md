# 多門配置試作版

本版保持全域 `W / H / D` 為整個箱體尺寸；多門分格只在 Door 分頁處理。

## Door 配置操作

- 啟用「多門配置」後，Door 分頁一次顯示完整盤面配置，不再使用單片「預覽」按鈕。
- 欄寬由左到右橫向排列。
- 每欄高度由上到下直向排列。
- Door Canvas 同時畫出所有格子；格內不顯示 `C?-R?`、尺寸或缺邊文字，只顯示該片已編輯的孔位/盲孔/指示燈孔。
- 欄寬 Entry 直接放在各欄上方；各層高度 Entry 直接沿格子由上到下排列，不再使用額外的欄/層設定面板。
- 單擊格子選取；雙擊格子直接開啟該片 Door 的統一開孔編輯器。
- 多門每一格擁有自己的孔位與指示燈設定；不會把某一片的孔複製到其他門。

## 自動補餘數

寬度與高度使用同一規則：最後剩餘尺寸由程式自動補上並以「自動」標示。

例如總尺寸 1000：

```text
輸入 400
=> 400 + 600(自動)

把 600(自動) 改成 400
=> 400 + 400 + 200(自動)
```

自動格只有在數值真的被修改時才轉成固定格；單純點入再離開不會失去自動狀態。刪除固定格後，餘數會重新計算。固定值超過總 W/H 時不建立負數格，GUI 會直接在 Canvas 顯示配置錯誤。

欄/層刪除不另外佔按鈕空間；在尺寸 Entry 上按右鍵可刪除固定欄或固定層。

## Door 尺寸規則

每一格的輸入值仍是 Door 計算起始尺寸：

- 右側還有欄：少扣一次 `FW + 2T` 的右框 allowance。
- 下方還有格：少扣一次 `FW + 2T` 的下框 allowance。
- Door 板本身仍使用既有 FourSideFlange 四邊折邊，不會因分格而刪除門板折邊。
- 既有 gap 算法維持不變。

## Door DXF 左右鏡像

Door 的 GUI、開孔座標、內部 DrawingScene 全部維持正常方向，只有輸出 DXF 的最後一步固定左右鏡像。

```text
Door canonical scene
-> export-only x mirror
-> DXF save
```

單門與多門皆套用同一規則，而且只鏡像一次。CUTTING、BEND、孔、BLIND_HOLE、MARKING、DATUM、CHECK 等有位置的 Door primitives 一起鏡像。非 Door 零件不受影響。

## 多門輸出檔名

```text
door_c1_r1.dxf
door_c1_r2.dxf
door_c2_r1.dxf

```

## 測試與暫存檔

正式 regression tests 全部位於 `tests/`。手動驗證輸出、範例 DXF、patch 或其他一次性產物放在 `tmp/`。

## Door 開孔、指示燈與指示燈盒子編輯

Door 第一頁可見控制只保留「啟用多門配置」。每一片 Door 的燈具方式都在該片的統一開孔編輯器中設定：

- `不使用`
- `直接指示燈`
- `指示燈盒子`

同一片門的「直接指示燈 / 指示燈盒子」互斥；不同門彼此獨立，所以多片門可以各自選擇不同模式。

- 單門：雙擊 Door 畫布開啟開孔編輯器。
- 多門：雙擊指定格子開啟該片 Door 的開孔編輯器。
- 直接指示燈：只在該片 Door 產生對應指示燈孔。
- 指示燈盒子：只在該片 Door 產生置中的盒體開口；多門輸出另外依格子產生 `indicator_box_cX_rY.dxf`，以及使用既有基準拉伸流程產生 `indicator_door_cX_rY.dxf`。
- 已附上實際工廠基準：`基準檔/指示燈/盒子.dxf` 與 `基準檔/指示燈/小門.dxf`。指示燈小門仍沿用既有基準拉伸流程；盒體公式已用 396×445 的 1層2組基準核對。
- 編輯完成後，主多門配置圖立即重畫該片的孔位/盒體開口。

### 箱體定位距離

勾選「箱體定位距離」後，Door 編輯器直接畫出箱體/分格的外框基準，X/Y 標線延伸到該外框；不是再顯示一個抽象的補償數字。

每一邊都獨立依該門的 `frame_edges` 計算：

```text
LEFT   = door_gap_w + (FW + 2T if left edge exists else 0)
RIGHT  = door_gap_w + (FW + 2T if right edge exists else 0)
TOP    = door_gap_h + (FW + 2T if top edge exists else 0)
BOTTOM = door_gap_h + (FW + 2T if bottom edge exists else 0)
```

因此 `3.5` 不是定位演算法的常數，只是目前 `door_gap_w / door_gap_h` 的常見預設值；寬、高 gap 可分別設定。有框的一側會加 `FW + 2T`，缺框的一側只保留該方向的 gap。

### 開孔編輯器操作調整

- 左側「插入」按鈕固定在零件區底部，即使縮小視窗仍保持可見、可按。
- 座標輸入浮動區的「確定」按鈕放在右邊，「取消」放在左邊。

## 基準檔來源狀態

編輯器會明確顯示目前零件是否真的使用基準檔：

```text
基準檔：金庫型/門.dxf
未使用基準檔（程式計算生成）
```

本試作包目前附帶：

```text
基準檔/金庫型/門.dxf
基準檔/金庫型/封頭尾.dxf
基準檔/金庫型/箱身.dxf
基準檔/指示燈/盒子.dxf
基準檔/指示燈/小門.dxf
```

- Door：單門與多門皆可使用 `金庫型/門.dxf` 的固定加工內容；多門仍依每格 `frame_edges` 動態決定結構尺寸。
- 封頭尾：沿用 `金庫型/封頭尾.dxf` 基準流程，封頭方向只正規化一次，之後 GUI/編輯/輸出皆為即見即所得。
- 箱身：主 CUTTING/BEND 仍由 StripFoldChain 公式幾何生成；若有 `金庫型/箱身.dxf`，只映射固定孔/加工特徵，狀態顯示 `基準檔：金庫型/箱身.dxf（固定特徵映射）`。箱身編輯改為左側 `D×H`、背面 `W×H`、右側 `D×H` 三面總覽；定位框直接使用 WHD，真正可加工完成面則內縮板厚 T。
- 指示燈盒：盒體目前仍為公式生成；`盒子.dxf` 用於工廠基準核對，不會假標成已載入。
- 指示燈小門：使用 `指示燈/小門.dxf` 基準拉伸。


## 箱身三面 WHD 編輯

- 箱身仍是一個實體零件，只輸出一張 `box_body_z.dxf`。
- 主畫面同時顯示左側、背面、右側三個面；快速第二次點擊某面進入統一開孔編輯器。
- 使用者定位尺寸直接使用輸入 WHD：左側=`D×H`、背面=`W×H`、右側=`D×H`。
- 例如 `W=500,H=600,D=200,T=2`：定位框為 `200×600 / 500×600 / 200×600`；實際完成面為 `196×596 / 496×596 / 196×596`。
- 孔位數值與標線以外層 WHD 箱體框量測；只有最後輸出時才轉成 `depth_left / front / depth_right` 的 StripFoldChain 展開座標。
