# WHD 正式版更新重點

**版本：** `v2026.10.30-x-9b7519164dd0`  
**正式產品來源：** `9b7519164dd08916deff42f3ff0790707f10d371`  
**上一正式版：** `v2026.10.29-x-df6d83931170`

## 本次主要更新

- **門板開孔與幾何**：加強原始 DXF 封閉輪廓、矩形邊界與座標驗證，拒絕不合法弧段、交叉邊界等異常資料。
- **多份 DXF 的資料保護**：補強原始檔備份、批次處理與中斷回復的內部驗證；這部分尚非全面開放的操作功能。
- **小門與外部工具串接**：補強指示器小門、門板及來源基準的對應核對；目前仍屬整合驗證階段。
- **Windows 版本交付**：補上正式 EXE、完整 ZIP、SHA-256 與繁體中文文件的發布驗收要求。

以上只整理實際版本變更重點，不逐條照抄開發提交。詳細技術差異：
https://github.com/looaeedr/whd/compare/df6d8393117052c97975045e46378a9fa0707806...9b7519164dd08916deff42f3ff0790707f10d371

## 下載與使用

下載 `WHD_Windows_x64_v2026.10.30-x-9b7519164dd0.zip`，完整解壓後執行 `WHD/WHD.exe`。更新前請備份設定、基準 DXF、CSV 和 `.p6fold` 專案，勿直接覆蓋舊版資料夾。GitHub Source code ZIP 不是執行版。

**驗收範圍：** Windows EXE 建置與啟動檢查不等於全部現場機型的製造驗收；CADCraft 外部程式不包含在 WHD ZIP 中。
