# WHD Windows 版使用說明

**版本：** `v2026.10.15-x-7c1d6f59e358`  
**適用：** Windows 64 位元  
**類型：** 可攜式資料夾版，不是單檔安裝程式

## 一、如何下載

1. 進入 [WHD 正式版本頁面](https://github.com/looaeedr/whd/releases/tag/v2026.10.15-x-7c1d6f59e358)。
2. 在頁面下方展開 **Assets（附件）**。
3. 下載 `WHD_Windows_x64_v2026.10.15-x-7c1d6f59e358.zip`。
4. 如需校驗檔案，再下載 `SHA256.txt`。

**注意：** GitHub 顯示的 `Source code (zip)` 是原始碼，不是可直接執行的 Windows 程式。

## 二、安裝與啟動

本版不需要安裝 Python，也沒有傳統安裝程式。

1. 把 ZIP 完整解壓到可寫入的位置，例如 `D:\WHD-Portable\`。
2. 進入解壓後的 `WHD` 資料夾。
3. 雙擊 `WHD.exe`。
4. 如要搬到另一台電腦，請搬移**整個 WHD 資料夾**，不能只搬移 EXE。

資料夾內常見內容：

```text
WHD/
├─ WHD.exe             程式入口
├─ config.ini          可編輯的預設設定
├─ 基準檔/             DXF、開孔及截角相關基準資料
├─ config/             其他設定資料
├─ 使用說明.md         本文件
├─ 本次更新.md         2026-10-15 更新紀錄
├─ 功能操作參考.md     專案既有的功能說明（部分為歷史參考）
└─ 其他程式執行所需檔案
```

**不要直接在壓縮檔視窗內雙擊 EXE**；必須先解壓縮，以免基準檔和程式不在同一個位置。

## 三、第一次使用

1. 開啟 `WHD.exe`，確認主視窗出現。
2. 先使用已有的基準型號或建立測試專案，檢查板件尺寸及 2D／3D 預覽。
3. 需要保存時，使用「**儲存專案**」或「**另存新檔**」，專案副檔名為 `.p6fold`。
4. 需要重新使用已有專案時，從「**開啟專案**」載入。
5. 開孔、折彎、截角及 DXF 的結果應依實際板件逐件檢查，確認後再用於生產。

## 四、3D 編輯與存檔要點

- 在 3D 視窗修改板件、折彎或開孔，屬於**尚未提交的草稿**。
- 按 3D 視窗的「**確定**」，才將草稿套回主畫面；按「**取消**」則捨棄此次修改。
- 主視窗的專案存檔以**已確定**的資料為準；不要把尚未確認的 3D 草稿誤認為已存檔。
- 切換板件、修改孔位或輸出 DXF 後，建議先用 2D／3D 核對實際位置，再進行生產。

## 五、更新舊版，保留自己的資料

**請勿直接以新版整包覆蓋原版資料夾。** 基準檔與設定可能是使用者自行調整過的資料，這份 ZIP 內附的是正式發行版本的資料。

建議流程：

1. 備份既有 WHD 資料夾；特別保留 `config.ini`、`基準檔/`、自訂 `CSV`/`DXF` 及 `.p6fold` 專案。
2. 將新版 ZIP 解壓到**另一個新資料夾**。
3. 先用新版附帶的基準資料確認能啟動，再**逐項比對**自訂設定與 DXF，不要未核對就整包覆蓋。
4. 用既有專案測試 2D、3D、開孔及 DXF，再決定是否正式改用新版。
5. 需要回到舊版時，直接使用備份資料夾即可；不必更動 Git 分支。

## 六、遇到問題怎麼處理

**雙擊無反應或啟動失敗**
- 確認 Windows 為 64 位元，ZIP 已完整解壓，而不是只移出 EXE。
- 確認 `WHD.exe` 旁仍有 `config.ini`、`基準檔/` 與其餘程式檔案。
- 可以查看 `logs/runtime_error.log`（若程式已產生），用來定位錯誤。

**看不到模型或基準檔**
- 檢查 `基準檔/` 的子資料夾、DXF 是否隨 ZIP 一起解壓，以及自訂的型號／檔名是否正確。
- 不要把不同版的基準檔混在一起後，直接當作同一份製造來源。

**Windows 顯示「未知發行者」**
- 本版**未簽署程式碼**。請先確認下載來自 [正式 GitHub Release](https://github.com/looaeedr/whd/releases/tag/v2026.10.15-x-7c1d6f59e358)，並可用 `SHA256.txt` 核對檔案完整性；不要為了執行而關閉系統防護。

**想確認本次修改了什麼**
- 閱讀同資料夾的 `本次更新.md`；GitHub Release 頁面也有繁體中文版本更新紀錄。
