## 本次主要更新

- **受電箱底板與 NFB 配置**：包含 [#2003](https://github.com/looaeedr/whd/pull/2003) 的雙深度 NFB／中心底板實體來源推導，以及 [#1999](https://github.com/looaeedr/whd/pull/1999) 的未配置底板和部分選取 DXF 匯出處理。
- **2D／3D、專案持久化、快取及製造防錯**：包含已驗收的 [#1796](https://github.com/looaeedr/whd/issues/1796) GUI、Save→Reload、DXF、碰撞與真 Windows Tk 回歸修正。
- **CADCraft**：保留原 WHD 2D 開孔編輯與製造資料來源；CADCraft 為使用者另外安裝的可選工具，第三方 CADCraft 程式不包含在本 ZIP 中。
- **正式發版驗證**： [產品回歸](https://github.com/looaeedr/whd/actions/runs/39289168514)、[Change Lane](https://github.com/looaeedr/whd/actions/runs/39289168434)、[知識治理](https://github.com/looaeedr/whd/actions/runs/39289168467) 對本次已驗收來源皆 SUCCESS。

這是相對上一個 2026-10-15 正式版的主要功能摘要，不是所有中間提交的逐項清單。

## 下載與啟動

Windows 64 位元可攜式 ZIP：`WHD_Windows_x64_v2026.10.20-x-3da51e25a324.zip`。

**只有 GitHub Release Assets 出現上述同版 ZIP 與 `SHA256.txt`，並且 Windows Runner 的建置及啟動測試均通過，才算 Windows 執行檔已交付。** GitHub 自動附的 Source code (zip) 只是原始碼。

完整解壓 ZIP 至新資料夾，執行 `WHD/WHD.exe`，不要只複製單一 EXE。保留 `config.ini`、`config/`、`基準檔/` 和程式附屬檔案。使用新版前，備份舊版自訂 DXF、CSV、`.p6fold`、`config.ini`；勿直接覆寫使用者資料。
