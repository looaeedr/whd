# WHD 正式版本更新說明（2026 年 10 月 15 日）

**版本：** `v2026.10.15-x-7c1d6f59e358`  
**已驗收的產品提交：** `7c1d6f59e3582bdff10af1c3d432d375341c0bea`  
**下載類型：** Windows 64 位元可攜式執行版（ZIP，內含 `WHD.exe`）

## 下載與啟動

請在本頁下方 **Assets（附件）** 下載 **`WHD_Windows_x64_v2026.10.15-x-7c1d6f59e358.zip`**，完整解壓縮後打開 `WHD` 資料夾，雙擊 **`WHD.exe`** 啟動。不需要自行安裝 Python。

ZIP 內包含繁體中文的 `使用說明.md`、`本次更新.md`，以及程式需要的 `config.ini` 與 `基準檔`。請勿只複製 EXE，必須保留整個資料夾。

請勿將 GitHub 自動顯示的 **Source code (zip)** 當成可執行版下載；那是原始碼，不是 EXE。

## 本次主要更新

本版本相較先前的 2026 年 9 月 28 日版本，累積了多項產品與介面修改。以下選列與操作最有關的已合併更新，不是全部提交清單。

### 一、受電箱、內門與開孔
- 受電箱內門採用與金庫型共用的實體板件拓樸，並支援從內門實體板件雙擊開啟既有開孔編輯器（[PR #1740](https://github.com/looaeedr/whd/pull/1740)、[PR #1744](https://github.com/looaeedr/whd/pull/1744)、[PR #1753](https://github.com/looaeedr/whd/pull/1753)）。
- 內門上層開孔編輯以**完整作業區 800 × 1100** 為定位尺寸，而非僅用內門本身下料尺寸（[PR #1760](https://github.com/looaeedr/whd/pull/1760)）。
- 整理實體板件的雙擊開孔入口，讓確認過的孔位資料接入實際製造資料（[PR #1761](https://github.com/looaeedr/whd/pull/1761)）。
- 改善受電箱底板與內門的對應、NFB 開孔、底板固定片及有條件使用的墊高片（[PR #1728](https://github.com/looaeedr/whd/pull/1728)、[PR #1727](https://github.com/looaeedr/whd/pull/1727)、[PR #1731](https://github.com/looaeedr/whd/pull/1731)）。

### 二、3D 預覽、折彎與碰撞
- 修正受電箱左側板折彎及其 3D／組合位置與基準檔的對應（[PR #1750](https://github.com/looaeedr/whd/pull/1750)、[PR #1751](https://github.com/looaeedr/whd/pull/1751)、[PR #1754](https://github.com/looaeedr/whd/pull/1754)）。
- 改善中隔真實厚度、可視性及各板件尺寸顯示，避免不必要的中央文字干擾（[PR #1752](https://github.com/looaeedr/whd/pull/1752)、[PR #1756](https://github.com/looaeedr/whd/pull/1756)）。
- 擴大 3D 組合碰撞檢查範圍，涵蓋封頭、左右框、中隔、側板等實體配對；預覽隱藏多餘三角網格雜線，保留真正的開孔與折彎線（[PR #1757](https://github.com/looaeedr/whd/pull/1757)、[PR #1759](https://github.com/looaeedr/whd/pull/1759)）。

### 三、介面與製造輸出
- 修正自訂板件設定視窗超出螢幕、難以操作的問題（[PR #1749](https://github.com/looaeedr/whd/pull/1749)）。
- 補強受電箱內門孔位與底板 DXF 的配對、輸出及重新讀取驗證（[PR #1728](https://github.com/looaeedr/whd/pull/1728)、[PR #1730](https://github.com/looaeedr/whd/pull/1730)）。
- 正式施工整合採 `localX` 作為日常來源，使用者的 `/推推` 同時表示驗收與正式發布授權；本版本已建立可核對的正式標籤與 GitHub Release（[PR #1765](https://github.com/looaeedr/whd/pull/1765)、[PR #1764](https://github.com/looaeedr/whd/pull/1764)）。

## Windows 可執行版本說明

- 使用 **Windows x64 GitHub Runner** 打包，程式內含 Python 執行環境。
- Windows Runner 已完成程式匯入、`WHD.exe` 啟動存活測試、ZIP 產出與 SHA-256 核對。
- 這些檢查**不等於已在使用者自己的 Windows 電腦完成全部 2D／3D、DXF 與實際專案操作驗收**。
- 此版本目前**沒有程式碼簽章**；如遇 Windows 安全警示，請確認官方下載來源與檔案雜湊後，依自己的安全政策處理。
- **不會自動覆蓋既有設定、基準資料或專案。** 若要更新舊版，建議先備份整個原資料夾及自訂的 DXF、CSV、`config.ini`、`.p6fold` 檔案，再將新版解壓到另一個資料夾測試。
