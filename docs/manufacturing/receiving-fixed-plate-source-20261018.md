## 驗證範圍

- 已有：實體原 DXF **CUTTING + BEND**，無需再向使用者索取「折線資料」；程式有來源 SHA 與 BEND guide，來源板形、孔位、每層四片 ID、裝配孔 X/Y/Z 可分別核對。
- 不自動假設：DXF LINE 的**±90°有向折向**、折後具體厚度 skin、焊接實際面與母側板展開 UV MARKING。前述需要把左右方向與真 3D fold skin 配合後才能提高 `formed_geometry_verified`／`weld_z_verified`。
- PAD 墊高片不是 EAR。PAD 未定，不得整張 #1503 HOLD。
- 來源是固定片原 DXF；**NFB 型號孔位**另以廠牌 `NFB數值規格.csv` 為來源，不需要 CSV→DXF→讀回中間轉換，也不因此強制正式加工 DXF 匯出。

> 原始 DXF CHECK 圖層文字有「內 R 與折彎補正核對」提醒；按本案已確認工廠不使用折彎補償，不把 K-factor 或折彎扣除列作核准要求，但仍須依原來源 BEND 驗證實際折向/折後皮面與焊接貼合。
