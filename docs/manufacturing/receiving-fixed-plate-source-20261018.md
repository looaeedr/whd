## #1503 以來源固定片實體尺寸推導不同箱寬孔距（2026-10-19）

本段**不修改** 2026-10-18 `固定片.dxf` 原圖，T2／大固定片 256×105、孔心 Y84、BEND23 都維持。箱身側板厚 `sideT` 與固定片來源厚 `earT=2` 是**兩個獨立尺寸**，不得一起硬套成 T2。

- 來源固定片折後孔心到**側板內側面**距離：`84 - 23 + 2 = 63 mm`。
- 箱體左右側板內面：`X = ±(W/2 - sideT)`。
- **固定片／底板固定孔的橫向裝配孔距**：`pitchX = W - 2*(sideT + 63)`；孔心在 `X = ±pitchX/2`，兩者都以箱體中心 X=0 為基準。此公式是從已存在的實體固定片來源折線反推，**不是**把 W800 的 670 直接當通用值。
- 例：W800／側板T2 → 670（X±335）；W750／側板T2 → 620（X±310）；W900／側板T2 → 770（X±385）；W800／側板T3 → 668（X±334）。上例固定片都還是來源 T2，並非把 `固定片.dxf` 擅改 T3。
- 各 NFB 層底板的 X 仍在箱體中心；NFB 橫向設定只改 NFB 螺絲孔，不可改底板、固定孔與固定片的箱體中心 X。Y 依該層實際 NFB 開孔群；雙層擁有各自不同的底板與左右固定片。
- 側板上的實體 `MARKING` 必須再用**真實側板 3D skin 接觸、source world→flat UV、Final Material、BEND 不相交及 DXF 重開**逐一證實；不能只憑上式就輸出非來源孔／整箱製造圖。源固定片 T2 與 T3 獨立圖號／折線、PAD 墊高片、未完成的數量版本／焊接工序仍不可冒稱已放行。

現行施工原碼：`receiving_weld_ear_policy.receiving_source_fixing_pitch_x_mm`，單層與雙層均使用同一來源公式。

## 側板安裝打標示意（2026-10-25）

使用者確認：**底板下緣＝固定片上緣＝唯一安裝定位點**。側板以這條真實上緣畫長向安裝 `MARKING`；在該線左右兩端各畫 **20 mm** 的短折邊示意線，形成下方開口的「ㄇ」型。**固定片下緣不畫線，不畫封閉矩形。**

20 mm 僅為側板 2D／DXF／3D 輔助打標線的**示意長度**，並非折邊製造尺寸，不能進入固定片 CUTTING、來源 BEND、折後實體、孔位、安裝 Z 或 BOM 的推導。固定片原圖 T2、`BEND=23 mm` 與 256×105 輪廓保持不變，真實 256×22 接觸面的焊接驗證及世界座標到側板平面 UV 投影仍照既有程式執行。
