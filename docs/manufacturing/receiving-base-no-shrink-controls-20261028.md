# 受電箱底板：取消手動縮邊功能（2026-10-28）

## 操作要求

受電箱底板在 3D 設定中心**不得顯示**「上縮邊、下縮邊、左縮邊、
右縮邊」或任何手動收縮輸入框。保留實體底板型式、
已知來源高度與折彎呈現；其他箱型的底板功能不變。

## 加工與資料界線

本次移除的是受電箱的**人工縮邊操作**，不是將物理板件
`shrink_top/bottom/left/right` 強制設成零。原始 LEFT/CENTER/RIGHT
來源的展開尺寸、折彎、四定位固定孔、PAD 裝配、2D/3D 與 MFG
仍使用同一個 `receiving_base_plate_values` 來源推導值，
保留舊 `.p6fold` 讀取相容性，不新增第二份幾何。

為避免破壞既有實體板件交易介面，UI 只將上述數值留為非視覺
狀態，用來維持已儲存／已推導實體底板的完整提交契約；
操作者看不到也不能從頁面修改這四個數值。
來源已推導的底板仍禁止手動套用，未知來源仍受既有核准阻擋。

## 驗收

- 真正的受電箱設定頁上不再有縮邊標籤和縮邊輸入框；
- 舊檔物理資料仍可保存與解析，顯示的展開形狀、孔位不應漂移；
- 其他箱型的同名預設設定與幾何不更動；
- 針對性 GUI 測試 + #1502 底板與 #1503 墊高片回歸 + PR CI；
- 未經使用者 /推推，不發布正式 X。
